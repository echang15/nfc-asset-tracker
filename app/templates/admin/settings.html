NFC reader setup

Keyboard-emulation (HID) readers work out of the box: open the scan station and tap a tag.

PC/SC smart-card readers (2-in-1 CAC + NFC readers, ACR122U, ACR1252U…) need the reader bridge. Start the app with it:

pip install -r requirements-reader.txt
python run.py --pcsc

Or run the bridge separately:

python reader_bridge.py --url {{ request.host_url.rstrip('/') }} --key {{ s.reader_api_key }}
